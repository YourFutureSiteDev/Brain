# Atomic notes make the graph useful

A note should hold exactly one idea. Not one topic, one idea.

## Why it matters

A note covering three ideas can only link as a lump. Every connection it makes is approximate, so the graph fills with edges that mean "these were written on the same afternoon" rather than "these ideas depend on each other".

Split the same content into three notes and each one links precisely. The graph stops being decoration and starts being a thinking tool, because a cluster now means something real.

The test: if the title needs the word "and", it is two notes.

## Evidence

The habit fails in the obvious way. A note titled "Outreach learnings" collects everything and gets opened never. [[Page one Maps results are the wrong prospects]] is one claim, so it surfaces every time the topic comes up.
