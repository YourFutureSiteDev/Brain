# Monthly review {{date:MMMM YYYY}}

Weekly keeps the vault clean. Monthly decides whether the work is going anywhere.

## 1. Kill something

The most valuable thirty seconds of the month. Open [[Projects.base|Projects]] and find the one that has not moved.

Mark it `#status/dead`, write one line saying why, move it to `08 Archive`. A stalled project sitting in the active list quietly taxes every decision you make.

- [ ] Something killed or explicitly renewed

- [ ] One seed grown into a real note

## 3. Stale work

- [ ] "Oldest untouched" reviewed. Anything genuinely finished archived.

## 4. Numbers

Run `_Meta/vault-stats.sh` and add the row to [[Vault Stats]].

- [ ] Stats updated

Links per note is the number to watch. Notes going up while links stay flat means capture without thinking.
