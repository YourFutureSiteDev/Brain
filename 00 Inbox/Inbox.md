# Inbox

This folder is a landing strip, not a home.

`Cmd+N` creates new notes here by default, so a thought can be captured without deciding anything about it. That is the whole point: deciding where something goes is a separate job from having it. See [[Capture and organise are different jobs]].

## Rules

1. Anything can land here. Half a sentence is fine.
2. Nothing stays. Every note gets filed, promoted or deleted at the weekly review.
3. Deleting is a normal outcome. Most captured thoughts are not worth keeping, and that is not a failure of capture.

## Where things go from here

| It turned out to be | Send it to |
|---|---|
| An idea worth keeping | `02 Notes`, rewritten as one claim |
| Something with a finish line | `04 Projects` |
| Something ongoing | `05 Areas` |
| Something someone else said | `03 Sources` |
| A person | `07 People` |
| A maybe | `02 Notes` with the Idea template |
| Nothing | Delete it |

Run [[Weekly Review]] to clear it.
