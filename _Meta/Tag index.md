# Tag index

The whole vocabulary. Adding a tag outside this list means updating this note first.

Topic tags are deliberately absent. Topics live in the `09 Maps` folder as maps of content, because a map can explain how things relate and a tag cannot.

## Type

One per note, set in frontmatter.

| Tag | Meaning |
|---|---|
| `#note` | Permanent note. One idea, in your words. |
| `#moc` | Map of content. An index into a topic. |
| `#project` | Has a finish line. |
| `#area` | Ongoing, no finish line. |
| `#source` | Something you read, watched or were taught. |
| `#person` | A human. |
| `#daily` | Daily log. |
| `#idea` | Unproven. Might become a project. Might die. |
| `#meta` | About the brain itself. |

## Status

Projects and ideas only.

| Tag | Meaning |
|---|---|
| `#status/active` | Being worked on now. |
| `#status/blocked` | Waiting on someone or something. Say what in the note. |
| `#status/someday` | Real, but not now. |
| `#status/done` | Finished. Move to `08 Archive`. |
| `#status/dead` | Abandoned. Keep the note, record why. |

## Note maturity

Optional, on permanent notes. Useful for spotting what needs work.

| Tag | Meaning |
|---|---|
| `#seed` | A fragment. Not yet a real thought. |
| `#grown` | Complete, linked, defensible. |
