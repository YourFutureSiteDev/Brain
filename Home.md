## Doing things

| I want to | Do this |
|---|---|
| Capture a thought | `Cmd+N`. It lands in `00 Inbox`. |
| Open today's log | `Cmd+P`, then "Daily note". |
| Start a project | New note in `04 Projects`, apply the `Project` template. |
| Find anything | `Cmd+O` for names, `Cmd+Shift+F` for text. |
| See the shape of it | `Cmd+P`, then "Graph view". |
| Insert a template | `Cmd+P`, then "Insert template". |
| Switch reading and editing | `Cmd+E`. This page is built for reading mode. |
